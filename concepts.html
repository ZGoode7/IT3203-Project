Seven Key Concepts

Important terms used throughout this research project.

1. Web browser

Software used to retrieve, display, and interact with web content.

2. URL

A web address that identifies a resource a browser can request.

3. HTTP

A protocol used for requests and responses between browsers and web servers.

4. Web server

A system that receives requests and provides web resources in response.

5. Rendering engine

Browser technology involved in turning webpage resources into visual content.

6. Browser compatibility

The ability of a website to function appropriately in different browsers.

7. Browser privacy

Features and practices related to limiting the collection or exposure of browsing information.
